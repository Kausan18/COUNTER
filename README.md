# 🌤️ Weather Forecast App

A beautiful, real-time weather application that shows current weather conditions and forecasts for 10 AM and 5 PM, with rain alerts!

## Features

- **Current Weather**: Real-time temperature, conditions, humidity, and wind speed
- **Morning Forecast (10 AM)**: See what the weather will be like in the morning
- **Evening Forecast (5 PM)**: Plan your evening with accurate weather predictions
- **Rain Alerts**: Get notified when rain is expected today
- **Beautiful UI**: Modern gradient design with smooth animations
- **Location Search**: Search for any city worldwide
- **API Key Storage**: Your API key is saved locally in your browser

## How to Use

### Step 1: Get a FREE API Key
1. Go to [OpenWeatherMap.org](https://openweathermap.org/api)
2. Sign up for a free account
3. Navigate to "My API Keys" section
4. Copy your API key

### Step 2: Open the App
1. Simply open `index.html` in your web browser
2. Or right-click and choose "Open with" → Your preferred browser

### Step 3: Enter Your API Key
1. Paste your API key in the input field at the bottom
2. Click "Save Key"
3. The app will automatically load weather for London (or your last searched city)

### Step 4: Search for Your City
1. Type any city name in the search box
2. Press Enter or click the search button 🔍
3. View current weather and forecasts!
